# Cola de videos

Normalmente no tocas esta carpeta: suelta tus videos en `content/inbox/` y el agente los acomoda aquí.
Si quieres hacerlo tú, pon aquí los videos terminados (verticales 1080x1920):

- `2026-10-27/01-video.mp4` → se publica el 27 a las 05:00. Tres videos en la carpeta = tres publicaciones a las 05:00.
- `2026-W44/video.mp4` → semana sin día: el agente los reparte (`plan_week`).
- El copy de cada video vive al lado: `01-video.post.yaml` (lo escribe el agente).

Detalles: `.agents/skills/content-queue/SKILL.md`.
