# TikTok — playbook (account @andrearuizdmn; not connected yet)

**Paths, best first**
1. TikTok Studio web `https://www.tiktok.com/tiktokstudio/upload` (logged-in Chrome): upload → caption →
   (optional) Schedule up to 10 days ahead → Post. Backend `browser` automates this flow.
2. Postiz (audited app) when the PC must be off.
3. `tiktok_api` only after TikTok audits the app (before that: SELF_ONLY/private).

**Caption**: hook first line, 3-5 hashtags (cap 5), the words people search (TikTok indexes caption, on-screen
text and speech). Footer lists Instagram + Facebook. Keep it casual.
**Subtitles**: "Captions" (auto) in Studio/app; edit wrong words before posting. No .srt.
**Sounds**: original audio is safest; trending sounds only if available for the account type.
**Don't**: re-upload the same file twice; watermark from other apps.
