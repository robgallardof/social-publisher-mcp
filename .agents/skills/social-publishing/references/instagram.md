# Instagram Reels — playbook (account @chomiescuincla; not connected yet)

**Before first post**: confirm the account is Professional (Business for the API, Creator works in the app/web),
and whether it is linked to the Facebook Page (then Business Suite can create/schedule IG reels too).

**Paths, best first**
1. Meta Business Suite reel composer with "Publicar en" = Facebook + Instagram (one upload, both scheduled).
2. `meta_api` (Graph API, Business account, no native schedule → runner posts at 05:00).
3. instagram.com → Create → Post → file → OK (becomes reel) → 9:16 → Next → Next → caption → Share.

**Caption**: first line ≤ 125 chars is all that shows; keywords beat hashtags; 3-5 specific hashtags; footer lists
Facebook page + TikTok (`brand.handles`). Cover: choose the frame with Chomi clearly visible.
**Subtitles**: auto captions toggle (Advanced settings); no .srt → burn when exact words matter.
**Don't**: post a TikTok-watermarked file; tag accounts the user didn't give; >1 broad hashtag.
