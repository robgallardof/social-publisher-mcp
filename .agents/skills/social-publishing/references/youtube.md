# YouTube Shorts — playbook (channel: ask the user; not connected yet)

**Paths**: YouTube Studio web (Create → Upload) with Schedule; `youtube_api` with `publishAt` (private-only until
the Google API audit); Postiz.

**Metadata**: `title` ≤ 70 visible chars, keyword first (e.g. "Ardilla rescatada: cómo llegó Chomi (Parte 1)");
description = caption + footer (IG/TikTok/Facebook); `tags` = search variants. Vertical ≤ 3 min → Short.
"Not made for kids" unless the user says otherwise.
**Subtitles**: Studio → Subtitles → upload `<stem>.srt` from `make_subtitles` (best accuracy) or auto.
**Series**: add Part 1/2 to a playlist; pin a comment linking the other part.
