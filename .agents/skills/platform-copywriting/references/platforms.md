# Platform limits

> Generated by `python scripts/sync.py` from `social_forge/domain/platforms.py`. Do not edit by hand.

| Platform | Duration | Caption | Title | Hashtags | Aspect | API limit/24 h | Native schedule |
|---|---|---|---|---|---|---|---|
| TikTok | 3-600 s | 2200 | - | max 5 (3-5 niche + 1 broad) | 9:16 1080x1920 | - | none (post at the time; TikTok Studio web can schedule up to 10 days) |
| Instagram Reels | 3-900 s | 2200 | - | max 30 (3-5 specific (more looks spammy)) | 9:16 1080x1920 | 50 | none (Graph API has no publish time: post at the time) |
| Facebook Reels | 3-90 s | 2200 | - | max 5 (0-3) | 9:16 1080x1920 | 30 | video_state=SCHEDULED + scheduled_publish_time (10 min to 29 days ahead) |
| YouTube Shorts | 1-180 s | 5000 | 100 | max 15 (2-3 (#shorts optional)) | 9:16 1080x1920 | - | status.privacyStatus=private + status.publishAt (ISO 8601) |

- **TikTok**: Unaudited API clients can only post SELF_ONLY (private). Saves, shares and completion rate rank.
- **Instagram Reels**: Business account (Instagram Login API). Cover frame and first line of caption matter; keywords > hashtags.
- **Facebook Reels**: Page Reels via /{page-id}/video_reels. Longer than 90 s is published as a regular video.
- **YouTube Shorts**: Unverified Google Cloud projects upload as private only until the API audit. Title = search keywords.
