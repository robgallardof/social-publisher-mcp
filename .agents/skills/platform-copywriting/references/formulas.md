# Hook and caption formulas

Use them as shapes, not templates to copy verbatim. Keep the promise the video keeps.

## Hook line shapes
| Shape | Example (es-MX) |
|---|---|
| Curiosity gap | "Nadie me dijo esto antes de adoptar un gato" |
| Stakes / consequence | "Si tu perro hace esto, llévalo al veterinario" |
| Contradiction | "Dejé de bañar a mi perro cada semana y mejoró su piel" |
| Number + specific outcome | "3 errores que arruinan tu arroz (el 2 lo hace todo mundo)" |
| Direct you | "Tú también lo haces mal: así se dobla una camisa" |
| Story in medias res | "El vecino tocó a las 3 a.m. y esto pasó…" |
| Part N | "Parte 2: lo que encontramos en el ático" |
| POV / relatable | "POV: tu mamá encuentra el control escondido" |

## Caption skeletons
**Entertainment**
```
<hook line>
<one line of context or punchline tease>
<question CTA>
#niche #topic #community
```
**Useful / tutorial**
```
<outcome in one line>
1) … 2) … 3) …   (only if the video is a list; helps saves)
Guárdalo para cuando lo necesites 📌
#topic #niche #format
```
**Series**
```
Parte <n>: <what changes in this episode>
Sigue la cuenta para la parte <n+1>
#series-tag #topic
```

## YouTube Shorts titles
- `<keyword> + <twist>`: "Gato vs pepino: no lo vio venir"
- `<how/why question>`: "¿Por qué los gatos le temen a los pepinos?"
- Avoid: "Video divertido #shorts #viral", emojis at the start, ALL CAPS.

## CTA bank
- Comments: "¿Team gato o team perro?", "¿Qué harías tú?", "Dime tu ciudad y te digo…"
- Saves: "Guárdalo para tu próxima…"
- Shares: "Mándaselo a quien siempre…"
- Follow: "Mañana subo la parte 2" (only when it is true: the queue has it)
